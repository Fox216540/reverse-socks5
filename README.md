# Как скопировать и запустить скрипт

## 1) Запустить gost 
```sh
gost -L "socks5://127.0.0.1:1080"
```

## 2) Сделать reverse в другом терминале
```sh
ssh -R "127.0.0.1:1080:127.0.0.1:1080" root@217.154.97.70
```

После запуска локальный SOCKS5 будет доступен на `127.0.0.1:1080`.


В этом случае локальный SOCKS5 будет на `127.0.0.1:1081`, и на VPS откроется реверс на порту `1081`.

## 4) Две SIM на одном телефоне

Если телефон без root, обычно активна только одна SIM для мобильных данных, и оба запущенных процесса пойдут через неё. Разделить трафик по SIM без root, как правило, нельзя.

Если в прошивке есть настройка привязки SIM к приложениям или “dual data”, можно попробовать запускать реверсы через разные приложения и привязать их к разным SIM. Это зависит от модели и прошивки.

Практичный вариант: два устройства (или телефон + модем/роутер), каждое со своей SIM и своим реверсом.
